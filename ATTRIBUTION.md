## Third-Party Open Source Libraries
Rust EXEL is built upon outstanding open source projects:
- **egui & eframe**: Immediate mode GUI for Rust by Emil Ernerfeldt and contributors (MIT / Apache-2.0).
- **calamine**: Pure Rust Excel and OpenDocument spreadsheet reader by Marc Chevrier and contributors (MIT).
- **rust_xlsxwriter**: Pure Rust Excel XLSX file writer by John McNamara and contributors (MIT).
- **formualizer**: Embeddable spreadsheet engine by psu3d0 and contributors (MIT / Apache-2.0).
- **csv**: Fast CSV parsing for Rust by Andrew Gallant (Unlicense / MIT).
- **serde & serde_json**: Efficient serialization framework by David Tolnay and contributors (MIT / Apache-2.0).
- **thiserror & anyhow**: Rust error handling primitives by David Tolnay (MIT / Apache-2.0).
- **tempfile**: Secure temporary file creation by Steven Allen and contributors (MIT / Apache-2.0).
- **chrono**: Date and time handling in Rust (MIT / Apache-2.0).
